# Recursos visuales

No se incluye ninguna imagen en esta versión inicial. No incorporar una imagen solo porque aparece en un buscador o en una página institucional.

Antes de agregar cada archivo:
1. Abrir la página de origen y revisar el estado de derechos/licencia.
2. Guardar una copia local autorizada y optimizada; evitar hotlinking.
3. Registrar la URL de la página de archivo (no solo el enlace directo al archivo), autoría atribuida, licencia, fecha de consulta y notas de procedencia en `docs/fuentes-y-licencias.md`.
4. Escribir texto alternativo útil cuando la imagen aporte información; usar `alt=""` si es decorativa.
